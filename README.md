# 🕹️ CoSE Arcade

A hub for original **lunar/space games** and browser-based **plant modeling & simulation tools**.

🌐 **Live site:** https://dr-richard-barker.github.io/cose-arcade/

## Games
- **Lunar Arcade** — dig-down Lunar Habitat (SimTower-style) + Boring Mining — [play](https://dr-richard-barker.github.io/lunar-arcade/)
- **Lunar Sims** — SimFarm-inspired lunar farming — [play](https://dr-richard-barker.github.io/LunarSims/)
- **Settlers of the Moon or Mars** — colony game + 3D-printable models — [play](https://dr-richard-barker.github.io/Settlers_of_the_Moon_or_Mars/)
- **Brute Bowl** — Blood Bowl–inspired arena / LLM game-theory — [play](https://dr-richard-barker.github.io/Training_LLM_game-theory_using_bloodbowl/)
- **Lunar & Martian Frontier** — frontier-colony prototype — [play](https://dr-richard-barker.github.io/Lunar-and-Martian-frontier-game-prototype/)
- **Lunar Red Alert** — OpenRA space-age total conversion (desktop mod) — [overview](https://dr-richard-barker.github.io/Lunar_Red_Alert/)

## Modeling & simulation tools
- **Seed Sowing Simulator** — [launch](https://dr-richard-barker.github.io/Seed_sowing_simulator/)
- **Virtual Root** (SimuPlant rebuild) — [launch](https://dr-richard-barker.github.io/virtual-root/)
- **LunarLeaf CFD** (leaf gas-transport) — [launch](https://dr-richard-barker.github.io/LunarLeaf-CFD/)
- **Aero-Leaf CFD**, **Statolith Physics Simulator**, **Leaf FDM Model (gravity-off)**, **Nature's Aerodynamic Analyser** — source-only (see the hub for links)

Third-party engine forks (habitat-sim, mars-sim, OpenRA) are excluded — these are original works and rebuilds.

*The hub page is served from `docs/`.*
