# 🕹️ CoSE Arcade

A hub for **original lunar and Martian browser games**, built from scratch in the spirit of the classic 1990s Maxis simulation games.

🌐 **Live site:** https://dr-richard-barker.github.io/cose-arcade/

## Games
- **Lunar Arcade — Lunar Habitat** — a vertical colony builder that inverts the tower genre (build up 26 levels, dig down 24), plus Boring Mining — [play](https://dr-richard-barker.github.io/lunar-arcade/)
- **Lunar Sims — Lunar Farm** — run the farm feeding a lava-tube colony at the Marius Hills skylight — [play](https://dr-richard-barker.github.io/LunarSims/)
- **Settlers of the Moon or Mars** — Catan × D&D × SimCity to teach space science; browser, AI tabletop, or 3D-printed board — [play](https://dr-richard-barker.github.io/Settlers_of_the_Moon_or_Mars/)
- **Brute Bowl** — a Blood Bowl–inspired planner/visualiser using LLMs for teams, characters and plays — [play](https://dr-richard-barker.github.io/Training_LLM_game-theory_using_bloodbowl/)
- **Lunar Red Alert** — a space-age total conversion of OpenRA (desktop mod) — [overview](https://dr-richard-barker.github.io/Lunar_Red_Alert/)

All original works — third-party engine forks (habitat-sim, mars-sim, OpenRA) are excluded.

*The hub page is served from `docs/`.*
